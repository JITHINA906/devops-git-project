# DevOps Git Workflow Project

A version-controlled DevOps project demonstrating Git and GitHub best practices.

## Objective

The objective of this project is to demonstrate:

- Git repository management
- Branching
- Feature development
- Pull Requests
- Merge operations
- `.gitignore`
- Git tags
- Documentation
